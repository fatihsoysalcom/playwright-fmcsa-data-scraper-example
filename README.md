# Playwright FMCSA Data Scraper Example

This Python script demonstrates how to use Playwright to automate web scraping of FMCSA data. It navigates the FMCSA website, searches for a company, and extracts basic information like company name and USDOT number from the search results.

## Language

`python`

## How to Run

1. Install Playwright: `pip install playwright`
2. Install browser binaries: `playwright install`
3. Run the script: `python fmsca_scraper.py`
